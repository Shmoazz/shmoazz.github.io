Location Based Intrinsic Reward

2021 Unity ML-Agents Solo experiment

The question

Standard practice rewards an agent only for the goal itself. I wanted to know whether paying it for behavior that tends to lead to the goal would train it faster, so I built a hummingbird agent in Unity that had to collect nectar from flowers, and gave one copy of it a reason to care about being in the right neighborhood.

How it was built

01 The environment

A Unity environment where the hummingbird navigates to collect nectar. The agent observes its own position and orientation in 3D plus a vector from the tip of its beak to the nearest flower's nectar hitbox. The baseline is purely extrinsic: reward arrives only when the beak lands inside the hitbox, and never before.

02 The intrinsic reward

I added triangular prism triggers arranged in a circular pizza slice pattern at the same Z level as the flowers. Entering one pays out a small reward and disables that trigger for the rest of the episode, so the agent is paid for covering new ground rather than for hovering in a spot it already found.

The idea being tested is narrow on purpose: reward the agent for exploring the altitude where flowers live, before it has ever touched one. If that shapes behavior, it should show up as faster convergence, not just a different looking policy.

03 Training and evaluation

Both models trained through Unity ML-Agents against a Python backend in an Anaconda environment, with a config file pinning the network architecture and hyperparameters so the only difference between the runs was the reward. I used TensorBoard to compare them over time.

Technologies

  • Unity
  • Unity ML-Agents
  • Python API for the network interface
  • C# for scripts and trigger logic
  • Anaconda
  • TensorBoard

Results

What came out of it

The location based intrinsic reward converged faster than the extrinsic only baseline. The shaped agents explored more efficiently, spending more of the episode where reward was possible and less of it in dead space. The takeaway I kept: reward shaping is not a detail you tune at the end, it decides what the agent bothers to learn.
